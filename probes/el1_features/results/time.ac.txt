=== el1_features: what a guest at EL1 under Hypervisor.framework can ACTUALLY do ===
    every probe runs in its own forked VM; the vCPU is put in EL1h (CPSR=0x3c5) before
    its first MRS, and VBAR_EL1 points at our own vector table so an undef is survivable

=== 4. the in-guest clock ======================================================
  CNTFRQ_EL0                = 24000000 Hz  (41.67 ns/tick)
  512 back-to-back MRS CNTVCT_EL0: 504 repeats, 0 decreases, smallest nonzero step 1 tick(s), largest 1
  monotonic: YES (no decrease observed)
  host mach_absolute_time around the run: 10680556419217 .. 10680557038851 ; guest's last CNTVCT 10680556437816
  => guest CNTVCT SHARES (same value range as) the host's mach_absolute_time timebase
  dependent ADD (1 cycle)    = 0.5819 ns  => guest clock ~ 1.72 GHz

  cost of reading the clock (median of 41 rounds x 16384 reads):
  empty loop body (floor)                    0.18 ns  [   0.17 ..    0.18]  net     0.18 ns      0.3 cyc
  ISB ; MRS CNTVCT_EL0                      20.15 ns  [  17.17 ..   22.57]  net    19.98 ns     34.3 cyc
  MRS CNTVCT_EL0 (no ISB)                    0.59 ns  [   0.59 ..    0.59]  net     0.41 ns      0.7 cyc
  ISB alone                                 19.17 ns  [  17.18 ..   20.21]  net    19.00 ns     32.6 cyc
  DSB ISH alone                              9.98 ns  [   9.98 ..    9.99]  net     9.81 ns     16.9 cyc

  the cycle counters:
    PMCCNTR_EL0   OK        host exits inside the window = 2  delta over a 4096-loop = 0  first trap ESR_EL2=0x6230e41b EC=0x18 (MSR/MRS trap)
    Apple PMC0    OK        host exits inside the window = 2  delta = 0  first trap ESR_EL2=0x6230bc01 EC=0x18
