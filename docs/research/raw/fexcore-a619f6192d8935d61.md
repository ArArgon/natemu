## A.5 What "half barrier" is exactly, and where the emit differs

The two barrier encodings: `/tmp/fexread/FEX/FEXCore/Source/Utils/ArchHelpers/Arm64.cpp:106-108`:
```cpp
constexpr uint32_t DMB    = ... | 0b1011'0000'0000; // Inner shareable all   (DMB ISH)
constexpr uint32_t DMB_LD = ... | 0b1101'0000'0000; // Inner shareable load  (DMB ISHLD)
```

Half-barrier = **one** barrier in **one** direction per access, rather than the two-sided `DMB ISH` sandwich a conservative emulation would use:

- **Load**: `LDR` then `DMB ISHLD` *after* it. Patched into `PC[1]` — `/tmp/fexread/FEX/FEXCore/Source/Utils/ArchHelpers/Arm64.cpp:2108-2121` (and the LDAPUR variant `:2134-2148`). Emulates acquire (nothing after the load may be reordered before it).
- **Store**: `DMB ISH` *before*, then `STR`. Patched into `PC[-1]` — `/tmp/fexread/FEX/FEXCore/Source/Utils/ArchHelpers/Arm64.cpp:2122-2133` (STLUR variant `:2149-2162`). Emulates release (nothing before the store may be reordered after it).

That is why the JIT's reserved `nop()` sits *after* loads and *before* stores. The store handler returns `-4` (`// Back up one instruction and have another go`, line 2132) so the freshly-patched `DMB` actually executes; the load handler returns `0`.

Vector TSO uses the same half-barrier polarity but emits it unconditionally at JIT time (no patching): `dmb(ISHLD)` after the vector load at `/tmp/fexread/FEX/FEXCore/Source/Interface/Core/JIT/MemoryOps.cpp:848-851`, and `dmb(ISH)` before the vector store at `:1828-1831`.

**Danger of half-barrier mode**, stated in-tree at `/tmp/fexread/FEX/FEXCore/Source/Interface/Config/Config.json.in:466-467`: once a site is backpatched, *aligned* accesses flowing through that same code become non-atomic (the LDR/STR is no longer an atomic single-copy load-acquire).

## A.6 Vector / SIMD TSO — there is no atomic 128-bit path

FEX does **not** attempt 128-bit atomicity. Vector TSO loads (`/tmp/fexread/FEX/FEXCore/Source/Interface/Core/JIT/MemoryOps.cpp:831-852`) are plain `ldrb/ldrh/ldr S/D/Q` (or SVE `ld1b` for 256-bit at `:840-845`) followed by `dmb ISHLD`. Vector TSO stores (`:1827-1848`) are `dmb ISH` followed by plain `strb/strh/str`. So the guarantee provided is **ordering only, not atomicity** — a 128-bit access can tear (in practice FEAT_LSE2 hardware gives single-copy atomicity for aligned ≤16B accesses for free, which is why this is tolerable).

Other vector sites with the same treatment: `VLoadVectorElement` `:1381-1384`, `VStoreVectorElement` `:1402-1405`, `VBroadcastFromMem` `:1462-1465`.

Because these are plain LDR/STR they never SIGBUS on misalignment, hence no `nop()` slot and no backpatching for vectors.

x87 opts out of vector TSO explicitly: `/tmp/fexread/FEX/FEXCore/Source/Interface/Core/OpcodeDispatcher/X87.cpp:182` and `/tmp/fexread/FEX/FEXCore/Source/Interface/Core/OpcodeDispatcher/X87F64.cpp:125` pass `MemoryAccessType::NONTSO` when vector TSO is off.

*Patched in place, then re-executed* — the four TSO forms, `/tmp/fexread/FEX/FEXCore/Source/Utils/ArchHelpers/Arm64.cpp:2108-2163`:

| Faulting insn | Rewritten to | Barrier slot | Return |

## C.2 The reserved `nop` — why the patch never needs to relocate anything

The JIT pre-reserves the barrier slot at compile time so the patch is strictly in-place, same size. Loads get `nop()` *after* (`/tmp/fexread/FEX/FEXCore/Source/Interface/Core/JIT/MemoryOps.cpp:799, 814, 829`), stores get `nop()` *before* (`:1803, 1819`), each carrying the comment `// Half-barrier once back-patched.` `memcpy` reserves two (`/tmp/fexread/FEX/FEXCore/Source/Interface/Core/JIT/MemoryOps.cpp:2170-2172`, `:2194-2196`). 8-bit accesses get no slot because they cannot fault.

## C.4 Cost and trigger frequency

- **Per-fault cost**: a full SIGBUS delivery + signal-handler entry + instruction decode + spin-lock + 2 code stores + `__builtin___clear_cache` (`/tmp/fexread/FEX/FEXCore/Source/Utils/ArchHelpers/Arm64.cpp:122-124`) + `ClearICache` + return-with-adjusted-PC and re-execution. Order microseconds.
- **Frequency**: for the *backpatched* classes this is **once per static instruction site, ever** — after the rewrite that site is a plain `LDR`/`STR` + `DMB` forever (until the block is discarded). For the *emulated* classes (`CASPAL`, `CASAL`, LSE RMW, `LDAXR` loops) there is **no patching**, so every dynamic execution on an unaligned address takes the signal — that's the pathological case, and it's why `StrictInProcessSplitLocks` and the kernel handler exist.
- FEX instruments it: `FEXCORE_PROFILE_INSTANT_INCREMENT(Thread, AccumulatedSIGBUSCount, 1)` at `/tmp/fexread/FEX/Source/Tools/LinuxEmulation/LinuxSyscalls/SignalDelegator.cpp:976`, counter declared at `/tmp/fexread/FEX/FEXCore/include/FEXCore/Utils/SHMStats.h:64`. No absolute rate numbers are checked into the tree.
- **Correctness cost of `HalfBarrier` mode** (default on): once a site is downgraded, *aligned* traffic through that same code loses single-copy atomicity — `/tmp/fexread/FEX/FEXCore/Source/Interface/Config/Config.json.in:466-467`. `NonAtomic` mode additionally drops the barrier entirely (`HandleType != NonAtomic` guards at `Arm64.cpp:2114, 2127, 2141, 2155`).

## Highest-value things to copy, regardless of FEXCore

1. **Reserve a `nop` next to every faultable atomic** so misalignment recovery is an in-place, same-size patch. Load→nop after, store→nop before (`MemoryOps.cpp:799` vs `:1803`).
2. **Store the barrier before downgrading the instruction**, with release ordering (`Arm64.cpp:2114-2118`) — the correctness crux for concurrent backpatching.
3. **Half-barrier polarity**: `DMB ISHLD` after loads, `DMB ISH` before stores (`Arm64.cpp:106-108`), and return `-4` from the store case so the new barrier runs.
4. **CF polarity as a compile-time symbolic bit** (`CFInverted`) rectified lazily with `cfinv`, with a GPR-XOR fallback (`OpcodeDispatcher.h:1754-1771`) — this eliminates almost all x86/ARM borrow-flag fixups.
5. **AF stored as `src1 ^ src2`, resolved at read against the PF byte** (`Flags.cpp:227-252`, `:182-192`) — AF becomes ~free because PF already saved the result.
6. **PF fully deferred to a 3-instruction XOR cascade, gated on a per-block `ReadsParity` bit** (`Flags.cpp:222-225`, `ALUOps.cpp:327-346`, `RedundantFlagCalculationElimination.cpp:746`).
7. **Software `axflag` in 2 instructions** (`csetm` + `ccmn`) for pre-FlagM2 hosts (`ALUOps.cpp:312-323`).
8. **Disable LRCPC2 by MIDR** on cores where `LDAPUR` is secretly full-acquire (`HostFeatures.cpp:445-466`).
