# Source ledger

This is an empty ledger template. It is populated only during separately
authorized research; organization alone does not collect, assess, or inherit
sources.

## Admissibility

Per the evidence policy, a Source-backed claim is admissible only when it is
directly supported by a primary specification, official documentation,
versioned upstream source, or peer-reviewed paper, with version, scope, and
applicability recorded at claim level. Secondary sources may help locate
evidence, but cannot carry a load-bearing claim. No inherited source is
accepted: a source must be inspected and recorded during the authorized work
that relies on it.

## Claim-level mapping template

Add one row for each source-to-claim mapping only after separate research
authorization and source inspection. A source that supports multiple claims
requires separate rows, one for each claim. The placeholder row below is a
non-entry example that describes the schema; it records no source or claim.
