# Investigation records

One file per separately authorized investigation, copied from the
[investigation template](../templates/investigation.md). This directory is
empty until research is authorized; its presence authorizes nothing.

- Identifier: `INV-<track>-<nn>`, where `<track>` is the two-digit track
  number and `<nn>` a two-digit sequence within that track, for example
  `INV-01-03`.
- Filename: `<identifier>.md`.
- Its experiment code, if any, lives in `experiments/<identifier>/`; its
  breadth passes, reviews, and manifests carry the same identifier.
