## Method rationale and self challenge

C1 supplies a fresh, fully enumerated prerequisite campaign while the full
timer method remains reopened. It retains all six clock APIs, expands QoS and
serialized clock contention to actual1/2/4/8 workers, and never replaces the
required fixed-phase timer cadence or global/strict dispatch investigations.
Downstream use requires independently accepted C1 result, replication and
adversarial findings, then each consumer's own interval/calibration checks.

The new raw-first contract makes counts and quantiles independently derivable.
Exact rational ns/read prevents truncation from deciding T1. Costs include
the wrapper, volatile sink and loop, not only the clock instruction. Zero
read-pair deltas are retained, and all200 fixed-size batches must exceed the
pre/post noise floor; insufficient resolution is unresolved, never a selected
subset or a smaller-count measurement. Wall-clock adjustment is not treated
as a monotonic-clock candidate, and no different clock families are subtracted
except the explicitly documented UPTIME_RAW/Mach relation.

Self challenge found that immediate containment sextuples could hide a
conversion error inside fixed slack. The proposal therefore requires256
sextuples per phase with inner intervals>=1ms and at least one width<=500ns,
plus all-sample containment with<=500ns slack. This retains the prior
containment principle but adds an explicit non-vacuity length. The busy-wait
control is disclosed as a perturbation outside cost batches. Synthetic ±1%
conversion controls must fail; their actual implementation remains unproved.

Serialized contention records acquisition order and actual worker counts;
it does not assume alternating workers or equate thread identity with cores.
All pthread outcomes and allocation bounds need code review. Native buffers
are bounded before launch and completed cells stream only outside measured
regions. API error/partial/timeout outcomes remain durable failure records;
no surviving child or wall-clock row may replace missing required evidence.

The separate executable must not invoke the old probe entry point, install
an unreviewed signal handler, inherit its schema gaps, or loosen its full-run
rules. Existing full-probe normal/negative obligations remain. Gate separation
allows prerequisite work; it does not constitute a completed investigation
or a change to the user's requested final state.
