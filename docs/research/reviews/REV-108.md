## Verdict

- Verdict: `revise`
- Rationale: `REV-104`'s single required change is fully closed and survives
  attack from both sides. The amended `Model C` definition makes the
  GPL-2.0-compatibility qualifier explicit and load-bearing, names `GPL-3.0-only`
  as the concrete case that fails, and gives the per-row reason from the
  record's own verified captures — Linux's non-UAPI source is GPL-2.0-only and
  QEMU's July-2013 directories accept version 2 and no later version — so a
  reader choosing a licence under `Q-01-01`/`Q-06-03` cannot land on the common
  modern copyleft licence and silently reintroduce the incompatibility `Model C`
  was added to remove. I tested the amendment for over-exclusion as well and it
  correctly admits `GPL-2.0-only` alongside `GPL-2.0-or-later`, and correctly
  refuses to adjudicate borderline copyleft licences rather than guessing at
  them. `accept` is nonetheless prohibited by one defect this commit
  introduced. `INV-01-01`'s Code-validation prose honestly records that
  `run.sh` changed after the accepted evidence run and has not been re-run,
  while its code gate row — the authoritative summary a later reader consults —
  still reads `passed` with `none` unresolved and names only `REV-039` and
  `REV-068`. The same commit edited `INV-01-10`'s code row correctly, to
  "Reopened for `run.sh`", so this is an inconsistency the author already knows
  how to avoid rather than an unclear standard. The action is one cell and is
  carried as `REV-109` R1 so it is not double-counted.
- Applicability limitations: This review challenges `INV-01-01`, `INV-01-10`,
  and `INV-01-11` only, at revision `8b9eadf`. It establishes no platform
  capability, no architecture selection, no legal conclusion, and no synthesis
  outcome; the `Model C` reasoning is licence-text analysis, not legal advice,
  and `INV-01-11`'s legal-uncertainty statement governs. Everything accepted
  remains bounded to `Mac16,10` (M4) / macOS 26.6.2 (`25G83`) / SDK 26.4 / CLT
  `26.4.0.0.1774242506`, ad-hoc signing, and non-Hardened-Runtime builds, with
  `P1` replication owed. The prior-involvement limit above is material and has
