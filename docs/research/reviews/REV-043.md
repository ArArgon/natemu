## Required changes

0. **Verified closed — the `REV-036` return.** Recorded here so the return is
   auditable and so no later reviewer has to re-derive it:
   - (0a) `CLM-01-07-03` narrowed. `mach_time.h` lines 46–50 declare
     `mach_timebase_info` and `mach_wait_until(uint64_t deadline)`; line 53
     `mach_absolute_time`; lines 58–62 the comment "like mach_absolute_time,
     but advances during sleep" and `mach_continuous_time`. A full-file grep
     for `deadline`, `nanosecond`, `units`, and `tick` returns only line 50.
     The claim's added sentence — "The header does not state which clock or
     units the `deadline` argument uses" — is literally correct. **Closed**,
     subject to required change 2.
   - (0b) `CLM-01-07-09` split. The claim now reads only "documents
     `pthread_kill` as sending a specified signal to a specified thread",
     which is verbatim the man page's DESCRIPTION ("The pthread_kill()
     function sends a signal, specified by sig, to a thread, specified by
     thread"). The exclusivity inference is out of it. **Closed.**
   - (0c) `CLM-01-07-10` scoped. `g2-man-sigaction.txt` lines 53–54 read "the
     signal is added to a set of signals pending for the process". The claim
     is scoped to "Darwin's captured `sigaction(2)` manual page" and its
     applicability says "Darwin capture only". **Closed.**
   - (0d) `CLM-01-08-02` narrowed. §B2.3 names the relation taxonomy including
     Ordered relations; §B2.6 lists Data Memory Barrier and "Load-Acquire,
     Load-AcquirePC, and Store-Release" under barrier functionality that
     includes "Ordering of load/store instructions". The claim now asserts
     only existence and identity of those constructs and explicitly disclaims
     one-to-one litmus correspondence. **Closed.**
   - (0e) `CLM-01-08-03` qualified. §11.1.2 states processors "will assert a
     bus lock ... (1) the access is to multiple cache lines (a split lock)";
     §11.1.2.2 "The integrity of a bus lock is not affected by the alignment
     of the memory field."; §11.1.2.3 "Support for split-lock disable is
     enumerated by IA32_CORE_CAPABILITIES[5]. Software enables split-lock
     disable by setting MSR_MEMORY_CTRL[29]. When this bit is set, a locked
     access to multiple cache lines causes a bus-lock violation that causes an
     alignment-check exception (#AC). The locked access does not occur."
     Every clause of the claim maps to captured text. **Closed.**
   - (0f) `CLM-01-08-05` corrected. §B2.2.1 gives the aligned
     single-general-purpose-register guarantee; §B2.8.2.1.1 gives the
     `FEAT_LSE2` conditional unaligned guarantee ("If all the bytes of the
     memory access lie within a 16-byte quantity aligned to 16 bytes and are
     to Normal Inner Write-Back, Outer Write-Back Cacheable, Shareable memory,
     the memory access is single-copy atomic") and the fallback ("not
     guaranteed to be single-copy atomic except at the byte access level").
     The claim no longer denies the conditional guarantee. **Closed.**

   §B2.6) are section landing pages and contain no `Barrier-ordered-before`

## Verdict

- Rationale: the return itself succeeds. All six `REV-036` required changes
  addressed to these two subjects are closed, and this reviewer verified each
  by re-extracting the cited text from the captures rather than by reading the
  author's closure note; every one of the eighteen capture digests and three

  line citation that excludes the cited token, an inference from source
  silence, a claim that omits a documented opt-out from the very page it
  cites, and a derivation contradicted by the next sentence of its own cited
  section) remain open. Applicable challenge dimensions therefore carry open
  required actions.

  Inferred claims and the source-to-claim mappings of `INV-01-07` at `c497cf3`
  and `INV-01-08` at `5fe6a68`, at the recorded digests. It reviews no
