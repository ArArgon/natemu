## Correction and self validation

REV-182's reproducer was valid: main could render eight histogram rows and
T1 before malformed T2 input raised. The correction wraps the whole selected
single-result/cohort path in one output buffer. A normal return publishes the
completed buffer; an input, arithmetic or rendering exception discards it and
returns nonzero with one failure line. This applies after pooled report
generation too, not only to the original single-result example.

Only the exception type is printed on an exceptional path. Its message may
itself contain partially rendered output, so echoing that arbitrary message
would undo the no-claims guarantee. Ordinary expected integrity/H-input
failure returns retain their detailed diagnostics because they finish
normally with nonzero status and contain no claims. Cohort parser exceptions
now report their exception type, not a detailed error message; that diagnostic
tradeoff is explicit, not a lost assertion that the input passed.

Three new pure regressions exercise production entry points:

- The exact late malformed `fallback_global_lock.ns_per_op` string supplied
  through CLI JSON loading returns1 with no H/corroboration/MEET/MISS prefix.
- A single-run report function renders its normal histogram rows and then
  raises RuntimeError carrying claim-like text; only the exception type is
  published, with none of those rows or message contents.
- The actual valid synthetic cohort path reaches pooled rendering, emits
  its normal rows inside the buffer, then raises OverflowError with claim-like
  text. Output is one nonzero failure line, without rows or member prefixes.

All 16 pure tests pass via `PYTHONDONTWRITEBYTECODE=1 python3
experiments/INV-01-08/tests/histogram-fixtures.py`; scoped `git diff --check`
passes. Existing valid output, early integrity failures, input validation,
exact classification, weighted pooling and exposure cases remain covered.
No actual cohort is authorized by these synthetic fixtures. The producer,
integrity predicates, timing thresholds, accepted method and immutable raw
evidence are unchanged. Full compilation/preflight remains deferred during
the live timer workload; these tests execute no probe.
