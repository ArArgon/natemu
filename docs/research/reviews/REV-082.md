## Verdict

- Verdict: `accept`
- Rationale: both results reproduced under independently prepared code. For
  `INV-01-09` the agreement is byte-identical where the data permit it —
  `unentitled.json` and `negative.json` hash the same in both runs, and
  `restricted.exit.txt` hashes the same as the original's
  `entitled-adhoc.exit.txt` — with the benign arm differing only in a label
  string. For `INV-01-14` every categorical result recurred and the single
  quantitative value moved by 0.0015%, which is what a live memory-footprint
  measurement should do. The independently written checker agreed with the
  author's on every arm, including rejecting both fault injections on exactly
  their fabricated fields, and its recomputations of sparseness, the
  punch-hole block drop, the footprint delta, and the refused-versus-clamped
  `setrlimit` distinction all matched the probe's own reporting. Rebuilding
  from `git archive 2e6118d` produced binaries byte-identical to the
  author's in both experiments, independently confirming the manifests'
  producing-code claim. The `com.apple.vm.networking` kill reproduced while
  the benign-entitlement control again exited cleanly with a valid signature,
  so the attribution is no longer resting on a single execution. No required
  action arises from this replication, every applicable challenge dimension
  carries a disposition, and independence is met under the reading disclosed
  above, so `accept` is permitted.
- Applicability limitations: this replication **widens nothing**. It ran on the
  same host and OS as the original runs, so every reproduced result stays
  bounded to `Mac16,10` (M4) / macOS 26.6.2 (`25G83`) / `MacOSX26.4.sdk`,
  ad-hoc-signed, unsandboxed, `uid=501`, `vmnet` host mode only, and `P1`
  replication remains owed before any platform-wide use. It approves no source
  claim, no method, no code, no result relabelling, no adversarial finding,
  and no synthesis outcome; the `REV-081` result-gate action remains open. It
  authorizes no planning and no implementation. Two same-day runs on one
  machine do not exclude a systematic host-state confound common to both.
