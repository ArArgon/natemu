## Response to independent required changes

1. R1: removed the second four-section template block. RETIRED prohibits
   execution/use of retained code pointers, not inspection of still-allocated
   immutable descriptors. Protected SUPERSEDED calls may finish. The same
   distinction now governs metrics, hooks and validation; no duplicate pending
   stub overrides deterministic negatives or sensitivity arms.
2. R2: E/V now name SC entries/page versions, immutable request records,
   release/acquire exact request/acknowledgement mailboxes, post-ack SC reload,
   minimum admitted page versions, zero-entry waiting and nonwrapping tokens.
   Only one epoch may be outstanding. The coordinator alone serializes version
   mutation, final validation, entry installation and invalidation completion.
   Invalidation zeroes obsolete entries before requests and drains all exact
   acknowledgements while holding ownership. Readers can acknowledge without
   a writer grant; V cannot await installation while withholding an ACK.
   The new post-successful-check/pre-install hook queues invalidation under
   held ownership; the inverse schedule rejects an already stale translation.
   A delayed unowned install is a named deterministic negative. The same
   version floor/reload applies to I's invalidation boundary, preserving its
   separate hazard protection, and S/M preserve STOP/RESUME exclusion.
3. R3: the per-arm outcome table allows old-current calls while an I/E writer
   is held before publication, distinguishes pre-hazard from advertised-hazard
   holds, permits protected SUPERSEDED completion, delays retirement as needed,
   and permits E/V post-ACK progress without adding RESUME. S/M require their
   stronger exclusion only. Causal attempt/release records identify events;
   instrumentation cannot acknowledge, clear hazards or add a global reader
   lock. The independent model must admit these valid paths as well as reject
   violations, and executable hooks remain required at actual 2/4/8 topology.
4. R4: zero clock pairs are retained quantization observations. All-zero
   coordinator calibration is resolution-unresolved, not a backward-clock
   claim. Every calibration batch must exceed a checked predeclared threshold;
   minimum-positive filtering is forbidden. The smallest qualifying fixed
   batch size is frozen before evidence, and every evidence batch/phase must
   exceed the final pre/post threshold or the child's quantitative cost is
   unresolved without selecting favorable observations. Backward/overflow or
   failed timer controls are invalid. Same-coordinator intervals, raw ticks,
   nested samples and no pure-API subtraction remain. The accepted same-host
   timer-result prerequisite remains mandatory before cost execution.
