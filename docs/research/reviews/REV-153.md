## Independent reasoning

Inferred from the declared event sequence: let `F_i` be the causal forward
duration and `A_i` the nonnegative remaining duration until the sender observes
the acknowledgement. Then `R_i = F_i + A_i`, so `F_i <= R_i`. There is no
reason for `F_i <= R_i/2`: `F=90 us, A=10 us` is a counterexample. This
arithmetic needs no platform-specific clock-comparability or path-symmetry
claim. It concerns the causal component of the measured sender interval, under
the existing clock/timebase method and its resolution limits; it does not
calibrate the independently subtracted cross-thread timestamp difference.

Inferred: pointwise inequalities over the same completed sample set imply the
same inequality for matching order statistics, including the producer's p99
rank. The current code fills `lat[got]` and `rt[got]` for the same successful
event and summarizes both with the same function/count. Thus the corrected
full-round-trip empirical p99 can bound the corresponding causal forward
empirical p99; it is not a guarantee about every event or future events. A
quantile-only I17 pass does not establish all paired inequalities or establish
clock comparability, as the amendment now explicitly states.

Observed in a development fixture only: the spinning-target row has one-way
p99 2584 ns and round-trip p99 2709 ns, with the old emitted half-bound 1354
ns. This is an internal reporting contradiction, not a host finding. The
current T3 predicate already tests sender round-trip p99 `< 200000`; its
numeric criterion need not change. Meeting that criterion alone cannot
establish the historical 100 us one-way target, which claim -15 now disclaims.
