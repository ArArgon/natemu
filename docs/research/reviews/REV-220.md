## Required changes

- None remaining in the reviewed text. The one defect found during this
  self-review (a cross-thread QoS-demotion call with no supporting public
  API) was corrected in the same drafting pass, before this verdict, by
  moving the demotion to each worker/timer thread acting on itself via a
  polled shared flag; the submitted Method section already reflects the
  fix.
- Outstanding, not required of this review but binding on later gates: an
  independent reviewer must independently re-derive that (a) the accepted
  packet's surfaces are used exactly as bounded by `REV-156`, with no
  IOKit reliance smuggled into a load-bearing claim; (b) the classification
  buckets in Metrics/Classification are genuinely closed and mutually
  exclusive; (c) the operator protocol's privileged commands and fallbacks
  are safe and complete; and (d) the sample-plan cell/seed/watchdog
  predeclarations are frozen before any code exists. No code may be
  implemented, and no execution may begin, before that independent method
  review passes and the subsequent code gate passes.

## Verdict

- Verdict: `accept`
- Rationale: as authored and corrected in this pass, `M21-1` is a bounded,
  qualitative host-lifecycle method that does not depend on the
  unaccepted `INV-01-07` clock instrument for any load-bearing conclusion,
  restricts detection to the independently accepted `REV-156` source
  surfaces (with IOKit named only as an unaccepted future supplement),
  declares operator-induced arms with an explicit non-simulated
  `not measured` fallback for transitions that cannot be safely or
  programmatically induced, and specifies positive/negative controls,
  integrity rules (fresh child, `NATEMU_RAW_ROOT`, watchdog ceilings,
  seeds), exclusions, stop criteria, per-claim falsifiers, and a
  same-host-only applicability statement. This self review finds no
  remaining defect in the proposal text, but it cannot itself satisfy the
  independence the executor guide requires: **independent method review is
  required before any code implementation**, and the code and result gates
  remain required before execution.
- Applicability limitations: method proposal only, for the single
  available `Mac16,10`/macOS 26.6.2 (build `25G83`)/SDK 26.4 host. No
  runtime observation, no lifecycle guarantee, no App Nap or forced-sleep
  finding, no platform-wide claim, no cost/latency number, and no
  synthesis or implementation authorization follows from this review.
