## Verdict

- Verdict: `accept`
- Rationale: Every one of `REV-039`'s ten required changes is closed, and the
  three that mattered were re-verified by re-running the exact fault injections
  that defeated the previous revision. A `MAP_JIT`-unavailable run — `KA-01`
  falsified — previously produced PASS and now produces FAIL naming two `KA-01`
  rules. A JIT write callback that writes nothing previously reported a
  successful callback-gated write with the right constant and PASSed; the region
  is now zeroed before the callback, the callback writes a distinct `43`, and
  the no-op injection is caught, reported false, and failed. The fault guard was
  rebuilt correctly rather than patched: locals are `volatile`, an armed flag
  gates the jump, the handler restores `SIG_DFL` and re-raises when no scope is
  live, and `print_mach_vm_remap` — the section that produced the infinite loop —
  is now itself guarded. Because that repair put my original injection inside a
  guarded scope, I wrote a fourth injection in a genuinely unarmed section to
  test the property directly: the process is killed by SIGSEGV with no output
  and no loop, where the previous revision spun forever emitting invalid JSON. A
  30 s watchdog backs it up. Beyond those, `sys_icache_invalidate` now precedes
  every execution as the cited source requires, unattempted Hypervisor calls
  emit `null` with `_attempted` flags, return codes are the unsigned hex strings
  the metrics name, the build moved to `mktemp -d` so nothing is written under
  `experiments/`, the repository guard resolves paths and derives its root from
  git — I confirmed the symlink that bypassed it is now refused — and
  `-isysroot` plus a recorded `readlink -f` and eight header digests tie the
  binary to the cited sources by construction. The build is warning-free on an
  independent recompile. No required action remains open, every applicable
  dimension carries a disposition, and independence is met, so `accept` is
  permitted; one advisory is recorded and is not an open change.
- Applicability limitations: This review accepts the code gate for
  `experiments/INV-01-01/` and nothing else, at revision `6c0acf5`, built and
  run on `Mac16,10` (M4) / macOS 26.6.2 (`25G83`) / `MacOSX26.4.sdk`. It
  establishes no platform capability and no `KA-01` or `KA-02` disposition:
