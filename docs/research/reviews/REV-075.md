## Required changes

1. `INV-01-05`, `CLM-01-05-15` (claim inventory line 112 and prediction table
   line 350): replace the label "Observed (in part)", which the evidence policy
   does not define. Either split the claim — an `Observed` claim for the
   negative whole-loop median (−0.1585 ns/store, with the existing and correct
   statement that it may not be attributed to the bitmap) plus a `Hypothesis`
   for the sign-consistency conjunct with the probe change owed — or relabel it
   `Observed` with the sign-consistency conjunct removed from the claim text and
   recorded as a limitation. The underlying judgment needs no change; only the
   label does. Owner: `t01_memory_author`. Return gate: result.
2. All four manifests (`MAN-01-03-01`–`MAN-01-06-01`) and the applicability
   cells of every timing claim: reconcile the host-load figure with the
   evidence. No `env.txt` contains a load reading, so "host load 2.43" is not
   supported by the digest-registered artifact. Either state plainly in each
   manifest that the load figures are an out-of-band executor observation not
   carried by the artifact, or add a load capture to `run.sh`'s environment
   block and re-run — the latter is a code change and would reopen the code
   gate, so the former is the smaller path. This reviewer's replication runner
   captures `sysctl -n vm.loadavg` and `uptime` and can serve as the pattern.
   Owner: `t01_memory_author` for the manifests and claims; main session if the
   code route is chosen. Return gate: result.
3. `INV-01-05`, `CLM-01-05-10` (line 108) and its prediction-table row (line
   346): stop quoting the 4.3% magnitude as an Observed figure. The attribution
   half (1000 identity matches, 0 mismatches, 0 faults without identity) is
   sound and must be kept; the direction of the cost effect may be kept; but the
   percentage must be recorded as not reproducible — the `REV-076` replication
   of the same binary on the same host measured +17.93% for the same quantity,
   and the single-thread spread exceeds both figures. Add the reproduction
   variance as a limitation, and route a properly powered contention measurement
   to `Q-04-01`, which already owns cost. Owner: `t01_memory_author`. Return
   gate: result.

## Verdict

- Verdict: `revise`
- Rationale: The integrity of this evidence round is genuinely strong and
  survived every check this reviewer could apply. All 28 manifest digests
  recompute correctly against the raw files, with no unlisted file and no
  listed-but-absent file in any of the four artifact directories. The manifests'
  most load-bearing argument — that the producing code is `cee40cb` even though
  `run.sh` stamped `2925831` — was verified independently three ways: 20/20
  identical Git blob hashes across the four experiment directories, a
  documentation-only diff at `2925831`, and, from the replication, a `probe`
  binary rebuilt from `git archive cee40cb` that is byte-identical to the one
  retained in each artifact. The environment captures match the stated host
  exactly and pin the ad-hoc signing configuration to the measured binary. All
  84 numeric literals in the Observed claims trace to the raw JSON, including
  the four that are derived rather than literal, each of which this reviewer
  recomputed. Both modes ran in every evidence run with the negative control
  firing. The relabelling from Hypothesis to Observed is disciplined, the
  applicability is bounded to this host and to ad-hoc signing everywhere, and
  the four kill-assumption claims are unusually careful — each says what it is
  *not* confirming and why. `accept` is nevertheless prohibited on three
  findings. `CLM-01-05-15` carries "Observed (in part)", a label the evidence
  policy does not define, so an honest judgment is expressed outside the
  vocabulary that governs inheritance. The host-load figure that every timing
  claim's applicability cell cites appears in no `env.txt`, so the one
  environment value bearing on every timing result is the one not carried by the
  digest-registered evidence. And `CLM-01-05-10` quotes +4.3% as an Observed
  magnitude that a same-host, same-binary replication moved to +17.93%. None of
  these touches a capability, soundness, or granularity result, all of which are
  solid; they concern how three numbers and one label are recorded. Three
  required changes are open.
- Applicability limitations: This review decides the result gate for
  `INV-01-03`, `INV-01-04`, `INV-01-05`, and `INV-01-06` and nothing else. It
  supplies no replication conclusion (`REV-076`), no adversarial conclusion
  (`REV-077`), and no synthesis outcome. Everything accepted here is bounded to
  `Mac16,10` (M4) / macOS 26.6.2 (`25G83`) / SDK 26.4 / Apple clang 21.0.0 /
  ad-hoc signing with no hardened runtime, at 1 and 2 threads with uncontrolled
  core placement; `P1` (M1 Pro / Sequoia 15) replication, the Developer ID and
  hardened-runtime cell, the ptrauth-enabled build cell, and 4- and 8-vCPU
  scaling all remain owed. No result here establishes a guest-visible property,
  a workload-relevant cost, or a family admissibility decision. Nothing here
  authorizes planning or implementation.
