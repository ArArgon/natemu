## Code challenges and corrections

The old mutex benchmark had no observed final oracle and could print a
qualified cost from zero/negative fabricated fields. The new candidate uses
a fresh128-aligned256-byte allocation, width4 offset78, fixed neighboring
canaries and explicit worker-only status slots. Four workers each set UI QoS,
publish ready via C11 atomics and await go/abort. Normal checks require all
four successful create/join/QoS records,250000 writes/iterations/locks/unlocks
per worker, observed final1000000 and no canary change. Create failure aborts
waiters. Lock failure cannot enter RMW. Unlock error stops work; unknown
ownership skips destruction/free even after successful joins. Failed join
serializes only coordinator-owned diagnostics and terminates without reading
live worker slots or destroying/freeing their objects. Blocking peers are a
supervisor timeout/failure, never a timed recovery.

The coordinator records start before create/end after final join. Wide integer
conversion of the tick delta is independently recomputed; T2 uses an exact
Fraction rather than an emitted decimal. Optional decimal validation uses
nearest/ties-to-even arithmetic. S1 enforces the unchanged fixed full sample
counts and positive primitive timing denominators. T4 now uses exact primitive
elapsed/attempt or elapsed/operation ratios and explicitly labels aggregate
harness cost, not isolated instruction latency or a guest cost floor.

The omitted-store mode counts999999 actual writes/final value against1000000
completed iterations. Its pure supervisor oracle repairs only those intended
differences in a copy, then requires every unrelated positive check; arbitrary
failed runs cannot pass as this control. Lock-error injection is worker0's
first iteration and never calls the lock/RMW there. Its oracle checks exact
injected EIO, zero worker0 work, truthful per-peer work sums and normal cleanup/
canaries, permitting scheduling-dependent peer counts without calling them
performance. Neither control is a normal eligible sample.

The unexpected path has no stdio, allocator, mutex, clock or JSON call: a false
probe flag goes directly to _exit90. Expected recovery additionally requires
the reported address within the active4-byte probe; the address is an
always-lock-free atomic word (compile-time requirement). U1 uses an independent
PROT_NONE child and parent-side status/raw/output checking. Its actual runtime
behavior is not yet observed. Expected alignment recovery remains the existing
bounded siglongjmp mechanism, not permission to recover arbitrary faults.

The first added handler disassembly check failed because Mach-O llvm-objdump
rendered imported stub targets under an unrelated symbol name, not because a
native test succeeded/failed. The check now uses the same optimized compiler
assembly for named imported calls, while preserving binary instruction-body
checks. The final preflight passed. No runtime sample was selected or excluded.
