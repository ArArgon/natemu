## Independent findings

### R1 — initial serialized-trace predicate gap, now closed

The initial inspected C1 required recomputation of per-worker and acquisition-ordered inversions,
but never explicitly states that either nonzero result fails the child. The
later zero-backward rule refers to the five monotonic **clock cells**; it does
not name the separate 1/2/4/8-worker contention cells. Similarly, the entirely
flat-clock rule follows the 200001-reading clock-cell discussion without
specifying its application to each contention trace/worker. Recomputing a
number is not an integrity predicate.

A concrete method-level counterexample is a two-worker trace with complete
unique IDs and all required samples, each worker internally nondecreasing,
but worker0's final timestamp1000 followed in acquisition order by worker1's
first timestamp999. It has the required inter-worker transition and no
per-worker inversion, but one acquisition-ordered inversion. All twelve
separate clock cells can still satisfy their zero-backward rules. This is a
symbolic counterexample to the incomplete acceptance wording, not an observed
host event or a test of not-yet-written C1 code.

Required: explicitly require zero inversions in both orderings of every
contention cell. Define the forward/zero/backward counts and denominators
for each worker and the full acquisition trace, and the unresolved/suppression
disposition if there is no positive advance. For example, each worker has
199999 adjacent differences and an n-worker global trace has n*200000-1;
the n=1 case still needs its stated flat/progress rule. If any required
worker/cell is flat or lacks the required inter-worker transition, it must
not support an accepted complete-child prerequisite merely because other
cells progress. Keep raw zeros, and do not fabricate progress by dropping them.

Add explicit valid-ID mutations for a global inter-worker-only inversion,
a per-worker inversion, and flat traces to the independent fixture contract;
ensure a runtime negative reaches a named contention inversion rejection,
not only the ordinary-clock-array rejection. Preserve all counts and matrix
coverage. Return this precise predicate/control correction to the method gate
before195 implementation. No source extension is needed to state an empirical
integrity requirement; it must not be promoted to a platform-wide coherence
contract.

### Independent closure of R1

explicitly fails the entire child on any per-worker or acquisition-ordered
inversion, independently of ordinary clock-cell checks. Every worker and
global trace must contain a positive step; flat required traces make the
child unresolved and suppress all findings. Derived forward/zero/backward
counts sum199999 per worker and n*200000-1 globally, and every emitted count
must match exactly. This covers n=1 without an invented inter-worker event.
