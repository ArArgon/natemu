### Protocol and lifetime correspondence

I uses SC entry/hazard load–advertise–revalidate and clears after the call;
retirement requires an empty matching-token scan. A protected SUPERSEDED
generation may finish; RETIRED code may not execute. S/M acquire every exact
ACK before mutation and release the matching RESUME. E publishes the new entry
before issuing its exact release epoch, and readers drop old-pointer rights
before ACK and reload before re-entry; it does not invent a RESUME. V constructs
and executes on the designated owner and services epochs while awaiting
installation without retaining the old code pointer.

The coordinator serializes final version check and installation with the
entire invalidation transaction, including removal, epoch drain and completion.
Both before-check and after-successful-check deterministic hooks exist; the
latter queues invalidation until installation has completed. Two producers
advertise independent wants but receive one exclusive grant. Shared ordinary
descriptor/request/job data is initialized before its release publication and
acquired before use. Fixed descriptors and request records survive all joins.
This is an author C-memory-order argument, not a native SMP finding.

Generation and epoch counters are nonwrapping 64-bit. Checked 32-bit descriptor
indexes are only bounded storage representations. A descriptor is24 bytes and
a request16 bytes, enforced by static assertions and recorded in raw plans.
The generated pair uses eight changed immediate fields. Before each physical
reuse, nonce selection checks that all eight fields differ; the checker
independently checks the recorded nonce, words, returned pair and reuse pair.
64/256/4096-byte blocks and both changed-field boundary layouts include the
hook prologue adjustment. The hook-only bounded helper is ordinary host code;
no hand-invented atomic instruction or signal-handler JIT API is introduced.

### Pressure, hooks and process-wide controls

M18-P1 setup actually publishes each H generation, witnesses intended-reader
calls, removes it, completes its drain, retires it, and retains that lifetime.
The two scratch reservations are never executable and transition to DISCARDED,
not RETIRED. Near-full I/E/V require actual no-free, release of a genuinely
retired H member, replacement publication/calls and arm-correct old-active
retirement, preserving the exact H-minus-released-plus-old-active set. V's
replacement stays on its recorded owner. Scratch occupancy causes the no-free
attempt; it is not mislabeled protected-reader backpressure. S/M retain their
distinct executable in-place reuse and allocator-only rejection observations.
The original held-reader hooks remain separate obligations.

Hook release depends on the intended competing state, not elapsed sleep.
Before-ACK requires all other exact ACKs. I/rate64 protected holds demand the
actual held token's retaining scan; pre-advertisement holds instead demand a
replacement and retry. Before-publication writer holds allow valid old-current
calls. With rate1 invalidation, progress may use the unaffected synthetic page;
this does not authorize calls through an already invalidated affected entry.
V cannot concurrently build and execute old code on its same designated owner,
so its coordinator wait witness is explicitly different.

Data remapping stays inside the exact owned file-backed window and records
different immutable backing offsets. Data protection uses the scheduled full
one/four-page extent. Whole-JIT protection uses the entire sole16 MiB arena.
The empty approved normal-context callback is an explicit candidate restoration
action after mprotect, including producer-thread acknowledgements and reader
restoration before re-entry; successful composition is not assumed. C never
calls the toggle API. Separate pre-thread sacrificial children implement N1's
actual adjacent data page or actual unrelated out-of-arena AOT/data control,
durable forbidden markers, expected fault status and restored returned pair.
No unrelated accessibility result stands in for JIT restoration or adjacency.

### Counts, cost, manifests and failure handling

The coverage packet retains I/S/E/V and all three M forms at1/2/4/8 readers,
A/B/C capability cells, and the exact one-factor variations. It contains482
cells:42,876 hook children,36 deterministic negatives,1,944 protection children,
1,446 sensitivity children,2,410 correctness children,7,230 cost children with
two baseline forms, and seven ordinary preflights. These are planned counts,
not completed experiments. Applicable/NA hook identities are explicit.

Post-warmup call snapshots prevent setup or warmup calls satisfying the fixed
16,384 per-reader evidence floor. Immutable descriptors are not recycled to
meet the cap. Exact allocation accounting includes full counts, H, two scratch
descriptors, the I/E/V replacement, up to2H+2 epochs, baseline pair arrays,
actual bounded trace/worker/slot arrays and a conservative1 MiB fixed-metadata
reserve. A plan exceeding256 MiB emits capacity-unresolved before evidence;
it does not reduce batches or silently complete that obligation. The cap is
owned metadata/trace buffers, not OS thread-stack reservation or process RSS.

Cost remains implemented but gated on independently result-accepted valid
same-model/OS INV07 input and local pre/post calibration. All10,000 pairs are
retained, including zeros. Exactly64 calibration batches at each1/16/256/4096
size select the smallest passing the fixed pre-threshold; all1,000 evidence
batches and reported timed phases must pass the final threshold. Whole-zero
calibration is unresolved, not backward-clock failure. No filtered favorable
tail, rebatching, cross-thread timestamp subtraction or half-RTT bound is used.
Separate phase8 measures immediate writer grant/request to acquired completion
or local writer operation; larger phase1 is not substituted for it. Other
phases cover ACK, mapping, resume, reclamation, installation-to-reader return
and stopped mutation. Intervals are nested and include trace overhead. Real
immutable data-indirection and metadata-handshake baselines are separate,
never subtracted into a claimed pure API cost.

Each actor uses a bounded single-writer release/acquire trace ring. Collector
sequence is actor-local, not global SC order. Only consumed ring storage is
reused; immutable generation/request identities remain. Trace/IO failure
invalidates the child. The supervisor preserves partial output, fsyncs final
artifacts, kills only its exact owned child at the30-second watchdog, and
retains blocked/unavailable cells in the frozen schedule. Durable cause-specific
witnesses plus expected state/status distinguish negatives from unrelated
crashes/timeouts. Cache/ISB omission and early cache publication remain
sensitivity tests whose finite pass is inconclusive.

The supervisor requires an independent code acceptance pinning both this
source packet and this build manifest, verifies actual signatures/hashes,
requires committed experiment source before runtime, and records producing
revision, environment, schedule, inputs and external immutable manifests.
Correctness requires full control qualification; cost also requires the full
correctness campaign. The present build records an uncommitted source packet
