## Independent findings

The method deliberately avoids common instrumentation errors: repair is by a
normal-context helper on a private non-JIT page; the handler neither changes
context nor clears protocol obligations; trace completion uses atomic records;
missing permission-denial telemetry is not inferred from a crash. Exact-PC,
address, nonce, thread and phase checks separate injected faults from host bugs.
No normal-return signal result is offered as a Mach reply result. These are
useful proposal boundaries, not observed success.

The required permission witness remains underspecified at a concrete boundary.
R runs while its synchronous SIGBUS/SIGSEGV handler waits for helper repair.
Testing a forbidden arena access inside that handler can raise the same
synchronous signal. The captured sigaction contract normally masks the signal
currently being handled, while M19-1 places SA_NODEFER only in separately tagged
diagnostics. The method does not say which mask/handler configuration makes
this mandatory terminal witness deliverable, or how its depth and classifier
remain distinct from the original recoverable event. An implementation cannot
silently add SA_NODEFER, assume the nested fault uses the other signal, or turn
an unrecorded crash into successful denial. A witness inside an already nested
positive handler also needs an explicit terminal depth policy distinct from
the two-positive-depth rule.

The method's exact Q18 protocol and delivered-Mach dependencies remain open.
The declaration-only M lane correctly refuses to pretend it has a method, but
that explicit gap means the whole proposed method cannot pass all required
scope now. Implementing a reviewed stage later is not completion of Q01-19.

   accounting for positive A/R/nested return separately from each sacrificial
   W/X denial witness. Cover same-class SIGBUS/SIGSEGV inside R explicitly;
   never assume the kernel chooses a different signal to avoid masking.
   Declare any SA_NODEFER witness configuration as its own experimental
   diagnostic, with same-cell preflight/classifier and watchdog requirements;
   it must not silently alter the admitted positive discipline. Define allowed
   terminal depth, slot ownership, parent linkage and exact fault PC/address
   checks, including a witness inside a depth-two positive handler. Preserve
   crash/partial/missing/blocked delivery as unresolved or failed coverage, not
   successful denial. Specify unique per-worker/per-event/depth witness storage
