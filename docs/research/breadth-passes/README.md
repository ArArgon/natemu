# Breadth-pass records

New breadth checks follow [the workflow](../README.md#conduct-an-investigation)
at question opening and track completion. Record discoveries once in the owning
investigation or question backlog, classifying current blockers, downstream
questions and retained unknowns. A check with none says `no new issues found`.

Existing `BP-*.md` files preserve question-opening coverage and historical
provenance. They establish no findings and are not live status summaries.
`BP-<track>-<nn>-start` and `BP-<track>-end` identifiers remain usable; new checks
can also be recorded directly in the investigation.
